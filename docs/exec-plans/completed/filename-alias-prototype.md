Status: historical prototype record. The user subsequently authorized installation

## Accepted behavior

Opt-in `provider_filter.hide.filenames` discovers workspace names locally and
projects stable structured session aliases. The existing session privacy
boundary owns publication, durable mappings and provider protocol validation.
Typed native tools resolve complete registered aliases before ordinary workspace
checks and approvals. Local files, content and presentation stay real.

The first prototype covers existing-file discovery, reads, scoped search/glob,
write/edit/patch/delete, and inherited native subagent contexts. Opaque shell,
MCP/custom tools, new files, alias-bearing patterns and hashline edits block.
No FUSE mount, local detector model or external proxy is introduced.
