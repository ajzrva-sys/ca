# Execution Plans

Complex work follows `.agent/PLANS.md`.

- Put live plans in `active/`.
- Move plans to `completed/` only after acceptance and validation evidence are recorded.
- Keep the corresponding `NEXT_STEPS.md` item as the queue pointer; do not maintain two competing task descriptions.
- Do not copy historical `.hermes/plans/` into this directory. Extract only still-valid evidence into a new plan.

No active plan existed when the harness was created. Create one before starting any task marked `ExecPlan`.
