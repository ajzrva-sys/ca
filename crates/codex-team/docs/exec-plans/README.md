# ExecPlans

Use ExecPlans for work too large or risky for a single `NEXT_STEPS.md` task.

## Locations

- `active/` - plans currently being designed or implemented.
- `completed/` - finished plans with validation evidence and retrospective notes.

## Workflow

1. Create a plan in `active/` using `.agent/PLANS.md`.
2. Link the plan from `NEXT_STEPS.md` instead of duplicating it.
3. Update the plan as commands run, surprises appear, and decisions are made.
4. When complete, record validation evidence and move the file to `completed/`.
5. Add follow-up tasks to `NEXT_STEPS.md` instead of leaving vague plan TODOs.

## Validation Evidence

Record exact commands, key results, skipped validation with reasons, changed interfaces, and known residual risks.
