

## Mechanistic Tools
The advertised repository-query and typed verification tools run directly through the shared local codex-team engine in this workspace. Use repository-relative paths with git_status, git_diff, git_log, inspect_symbol, inspect_feature, find_relevant_tests, verify_changes, and verify_recipe only when those exact tools are available. Inspect their native receipts and integrate the results. Ordinary read_file, search_files, glob, and list_dir retain their filesystem scope, including untracked files and non-Git workspaces. Do not replace a failed typed verification with an unsupported success claim. Verification uses the exact current candidate in an isolated copy; full-suite execution remains subject to the existing execution policy. No special MCP profile is required. Explicitly configured external backends retain their own repository and policy binding. Automation setup and remote operations are available only when their specific tools are advertised.
